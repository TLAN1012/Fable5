⚙️ API 設定

如何申請(約 5 分鐘,免費):
  1. 到 Google Cloud Console 建立專案
  2. 「API 和服務 → 程式庫」啟用 YouTube Data API v3
  3. 「憑證 → 建立憑證 → API 金鑰」→ 貼到上方第一欄
  4. 「憑證 → 建立憑證 → OAuth 用戶端 ID」類型選網頁應用程式, 「已授權的 JavaScript 來源」加入 https://tlan1012.github.io (本機測試另加 http://localhost:8000)→ 貼到上方第二欄
  5. 「OAuth 同意畫面」加入自己的 Google 帳號為測試使用者即可使用
金鑰只儲存在你自己瀏覽器的 localStorage,不會上傳到任何伺服器。
